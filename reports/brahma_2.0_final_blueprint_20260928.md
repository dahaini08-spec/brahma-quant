## 2. 苏摩全面理解（决策指纹画像）

从285次苏摩111裁决+6个月commit语料提取：

**核心理念**：
- 「系统说了算」——不抗单、止损即出、数据驱动（USER.md原文）
- 期望值思维：反复强调EV、RR≥1.5、WR矩阵口径不混用
- 痛恨重复犯错（AGENTS.md: "每条规则来自真实loss"）
- 痛恨系统不守约（"最烦: 系统说了不算"）

**协作风格**：
- 快决策：111=立即执行，停止=立即取消，从不纠缠细节
- 重视证据链：E1裁决要求executor日志>推算>记忆
- 给AI充分自主权但保留终审权（最高批准权=唯一一票）
- 喜欢结构化表格+结论在前（沟通偏好USER.md）

**战略方向**：
- 三拳头产品（VIP期货/现货/自动）是商业化的骨架
- 直播+SMC教学+每晚21:00 = 个人品牌路线
- A线内容与B线交易分离（9.26封印）是苏摩亲自裁决的架构

**给2.0的含义**：苏摩要的不是更多分析维度，是**一个说话算数、证据闭环、少操心的系统**。

## 4. 顶层全局新方案（梵天2.0 终版蓝图）

### 4.0 设计宣言

> **砍到只剩赚钱必需的东西。25K行预算不妥协。每个cron有消费者，每个维度有IC，每笔交易有证据链。AI议会出裁决，苏摩111出终审，其他一切都是噪音。**

### 4.1 一页架构（终版）

```
                    ┌─────────────────────────┐
                    │   苏摩111 (终审/解锁)      │
                    └───────────▲─────────────┘
                                │ 桶解锁/紧急停止
┌───────────────────────────────┴───────────────────────────┐
│ L3 执行层  paper_executor (唯一执行入口, 双硬闸)              │
├───────────────────────────────────────────────────────────┤
│ L2 风控层  risk_gate R1-R5 (fail-closed, 无旁路)            │
├───────────────────────────────────────────────────────────┤
│ L1 信号层  纯函数: 12维+体制门+方仓匹配 → signal dict        │
├───────────────────────────────────────────────────────────┤
│ L0 数据层  MarketData (唯一网络出口, 录制模式, STALE拦截)     │
├───────────────────────────────────────────────────────────┤
│ L-1 证据中枢 EvidenceHub: append-only事件流 + IC周审 + 桶审   │
└───────────────────────────────────────────────────────────┘
        ▲                                    ▲
        │ 同一信号包(只读)                     │ 结算反馈(唯一回流)
┌───────┴────────┐                   ┌───────┴────────┐
│ A线内容引擎      │                   │ AI议会(每日1次)  │
│ VIP卡/Square/直播│                   │ 复盘+IC裁决建议  │
└────────────────┘                   └────────────────┘
```

### 4.2 数据流铁律（新增，1.0没有的）

1. **append-only事件流**: `events.jsonl` 每行一个不可变事件（signal_fired/gate_blocked/order_opened/position_closed/pnl_settled）。**禁止UPDATE，只许APPEND。** 修正=追加correction事件。账本翻案从物理上不可能。
2. **单一写入者**: 只有settlement进程写ledger视图；其他全部只读事件流。9.26竞态双tick类事故从架构上消灭。
3. **信号包SSOT**: A线/B线读同一个signal包（≤2h新鲜度），square_auto_post不再重跑分析。
4. **降级路径显式**: LLM不可用→议会出"本地规则降级"标记事件，不静默装作正常。

### 4.3 B线交易管道（12维终选）

**保留12维**（IC已证明或逻辑必然）:
1. regime_direction（体制方向，80%胜负手）
2. regime_multiplier（体制乘数表）
3. fvg_mid_distance（FVG中点距离→入场位置）
4. ob_validity（OB age<50未穿越）
5. liq_cluster（清算地图集群距离）
6. resonance_score（7维共振点）
7. rsi_extreme（超买超卖极值）
8. bb_squeeze（挤压突破）
9. fangcang_match（标的专属方仓匹配>0.4）
10. hurst_regime（趋势/均值回归确认）
11. atr_sl_ratio（SL距离/ATR1H铁律比）
12. cost_model（taker+滑点+funding后EV）

**冷冻待IC翻案**: HAR-RV、GEX、聪明钱、OI极端值、宏观事件、PIP几何、CVD明细、MTF共振等（数值继续记录，权重=0，复活需连续2周IC>+0.02+苏摩111）

### 4.4 cron终版清单（66行→22行，AI 17→11）

**B线（确定性，7个）**:
- state_refresh 30m / battlefield 7m / paper_executor 1h / tp_monitor 5m / settler 30m / resurrect 1m / sentinel 15m

**A线内容（AI，8个）**:
- auto-analysis 3h / VIP晨报 01:00 / VIP晚报 09:00 / square_auto_post 2次 / blood-chip 2次 / heat+education / weekly-deep

**治理（AI，3个）**:
- daily_review 23:30 / IC周审(周一) / 桶效力月审(1日)

**砍掉**: chop-breakout-watch(12次/天→0，由state_refresh的决策事件替代)、afternoon重复分析、event-news（并入heat）、live-preview/recap合并、brand-identity（降周1）

**AI预算**: 11个任务≈26次/天 ≤33 ✅

### 4.5 证据驱动循环（心脏）

```
纸面交易 → settlement → events流 → IC周审(周一09:00)
  → 维度权重±10%/冷冻 → 桶效力月审(1日)
  → 桶n≥30且WR≥52%且EV>0 → 苏摩111解锁实盘
证伪条款: 任意桶30笔EV≤0 → 自动冷冻，不讨论
```

### 4.6 会话工程学铁律（新增，9.28教训）

1. subagent任务必须带探索预算上限（"≤40次工具调用，先写骨架后补细节"）
2. 主session建造=单文件单次写入+立即commit（gateway随时重启）
3. 长评估一律主session直跑，不赌subagent
4. 工具调用>60次自觉收尾，把状态写盘再结束

### 4.7 三拳头产品线（A线，保留增强）

- **VIP卡片**（期货）：格式永久封印不变，数据源=signal包SSOT
- **现货策略**（拳头二）：spot_strategy_square保留
- **自动纸面**（拳头三）：B线paper盘=真实证据源，桶解锁后直通实盘
- **直播/教学**：SMC课程体系+live脚本复用，不新增AI cron
