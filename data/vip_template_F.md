## 字段说明

| 字段 | 来源 | 说明 |
|------|------|------|
| 日期 | 系统时间 | YYYY-MM-DD |
| 体制名称 | 梵天GATE-0 | 熊市趋势/牛市趋势/震荡 |
| REGIME_TAG | 梵天 | BEAR_TREND/BULL_TREND/CHOP_MID |
| 价格/涨跌幅 | 实时行情 | 现货价 |
| 进场区 | 35维矩阵 | Bull/Bear OB + FVG区间 |
| 止损 | 梵天封印公式 | SL_PCT * 进场区沿 |
| 目标 | 结构TP | 流动性猎杀位/BOS位 |
| 仓位/杠杆 | position_sizer | 体制映射表 |
| R:R | 自动计算 | (TP-进场)/(进场-止损) |
| WR/N | wr_matrix_v7 | 历史回测数据 |

## 体制→主策略映射

## 胜率参考（双源标注 · 设计院 2026-07-26）

> ⚠️ **重要说明**：以下区分「历史回测」与「实盘实测」两个来源，不可混用

### 历史回测（wr_matrix_v7 · 大样本长周期）
- BEAR_TREND做空：BTC 72.3%(n=1041) / ETH 73.7%(n=1057)
- BULL_TREND做多：BTC 74.1%(n=987) / ETH 71.8%(n=1023)
- CHOP区间：BTC 68.5%(n=612) / ETH 66.9%(n=589)

### 实盘实测（wr_matrix_realtime · 当前信号日志 · 2026-07-26）
- 整体WR = **41.6%**（清洗掉SL违规信号后，n=120）
- BULL_TREND LONG 140-154 = **0%**（死亡区间，已封印PENALIZE）
- score < 130 = **44%**（基础信号质量正常）
- 说明：实测样本较小（n=120），随信号积累持续更新

> VIP播报中展示「历史回测值」时，需注明：「历史回测 WR=72%，当前实测WR=42%（积累中）」

## 禁止事项

- ❌ 禁止在模板中加入技术指标描述（RSI/OB/FVG等术语）
- ❌ 禁止超过模板行数（VIP群员看简洁策略，不看分析）
- ❌ 禁止混入1号工程分析内容
- ❌ 禁止修改▋▋边框格式
- ✅ 只输出：方向 · 进场 · 止损 · 目标 · 仓位
