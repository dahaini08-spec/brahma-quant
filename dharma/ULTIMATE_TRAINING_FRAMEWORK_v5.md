## 维度③：盲测高胜率指标技术组合

### 核心命题：去掉梵天评分器，纯用统计盲测，哪些指标组合真正有预测力？

```
方法：
  1. 不用评分器，不用人为权重
  2. 对每个指标单独计算IC
  3. 对指标组合计算联合IC
  4. 用Bonferroni校正多重比较
  5. walk-forward验证稳定性
```

### 盲测指标矩阵

| 指标 | 计算方式 | 单指标IC | 组合IC | 验证标准 | 优先级 |
|------|---------|---------|--------|---------|--------|
| **体制×方向** | regime_map + direction | ? | | IC>0.02 | P0 |
| **FVG方向** | bull/bear/none | ? | | IC>0.01 | P0 |
| **OB有效性** | valid/invalid | ? | | IC>0.01 | P0 |
| **清算密度** | liq_density 0-1 | ? | | IC>0.01 | P0 |
| **共振强度** | 0/1/2/3 | ? | | IC>0.03 | P0 |
| **RSI** | 0-100连续值 | ? | | IC>0.005 | P1 |
| **BB宽度** | %连续值 | ? | | IC>0.005 | P1 |
| **成交量比率** | vol/avg_vol | ? | | IC>0.005 | P1 |
| **ATR%** | atr/price | ? | | IC>0.005 | P1 |
| **EMA9方向** | 上/下 | ? | | IC>0.005 | P1 |

### 盲测验证流程

```
Step1: 对每个指标单独计算IC → 找出IC>0的指标
Step2: 对IC>0的指标两两组合 → 找出联合IC>单指标的组合
Step3: 对最优组合做walk-forward → 验证样本外稳定性
Step4: 对比盲测最优组合 vs 梵天评分器
  → 如果盲测IC > 梵天IC = 梵天评分器维度选错了，应该用盲测结果
  → 如果盲测IC < 梵天IC = 梵天评分器维度选对了，人为权重有价值
  → 如果盲测IC ≈ 梵天IC = 可以简化评分器（去掉人为权重）
```
