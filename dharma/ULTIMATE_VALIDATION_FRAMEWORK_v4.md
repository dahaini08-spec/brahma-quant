## 二、达摩院铁律（不可违反）

### 铁律1：零上帝视角
```
信号在i收盘时确认 → i+1开盘入场
体制标注用前一根已收盘4H → 不用未收盘的当前4H
出场扫描从entry+1开始 → 不用信号K线数据
```

### 铁律2：真实成本硬扣
```
每笔扣除0.08%（Taker 0.05% + 滑点0.03%）
净EV = 毛EV - 0.08%
门槛：净EV > 0.08%/笔 才算有效（双倍成本门槛）
```

### 铁律3：ATR动态出场
```
SL = ATR × 1.5（不是固定2%）
TP = ATR × 2.0（RR≈1.33）
结构失效：EMA9穿越EMA21 → 提前出场
MAX_HOLD = 48根（保险，动态出场优先）
```

### 铁律4：19折Walk-Forward
```
训练24月 → 测试6月 → 步长3月 → 滚动19折
每折独立计算EV → 汇总取均值
稳定性 = 正EV折数/总有效折数 ≥ 60%才通过
```

### 铁律5：独立否决权
```
达摩院保留独立否决权：
  19折中超过5折WR<50% → 系统判定不可用
  跨标的泛化<3个通过 → 策略判定过拟合
  任何单项V07滑点20bp后WR<48% → 策略判定不可执行
不管梵天引擎WR多高，达摩院否决=最终否决。
```

## 三、12项验证详细方案

### Layer 1: 数据可靠性（V01-V03）

| 编号 | 验证项 | 方法 | 达摩院标准 | 状态 |
|------|--------|------|----------|------|
| **V01** | K线完整性 | 时间连续性 + OHLC合理性 + 零成交量 | gaps<0.1%, zero_ohlc=0 | ✅ 已通过 |
| **V02** | 体制标注一致性 | 切换频率5~15% + 人工抽检100条 | 7.5%切换率, 无异常时间戳 | ✅ 已通过 |
| **V03** | 前视偏差修复 | **达摩院铁律1：i-1收盘→i开盘入场 + 体制用前一根4H** | 修复后WR下降≤3% | **P0** |

**V03执行方案：**
```
修改brahma_backtest_v3.py:
  1. 体制获取：regime_map.get(ts_4h) → regime_map.get(ts_4h - 4*3600*1000)
     即：用前一根已收盘4H的体制标注
  2. 入场价：b['c']（收盘价）→ bars[i+1]['o']（下一根开盘价）
     即：信号确认后，实际可执行的第一个价格
  3. 指标计算：所有指标用bars[i-1]的数据，不用bars[i]
     即：只用已收盘的K线数据生成信号

预期影响：WR下降1~3%（从55.7%→53~55%）
验证标准：修复后WR≥54% = 通过
```

### Layer 2: 策略有效性（V04-V06）

| 编号 | 验证项 | 方法 | 通过标准 | 优先级 |
|------|--------|------|---------|--------|
| **V04** | 评分器单调性 | score分10档，WR是否递增 | 115~130段修复或排除 | **P0** |
| **V05** | IC分层验证 | 按年份+周期+标的分层IC | 各层IC>0且稳定 | P1 |
| **V06** | Wilson+多重比较 | Bonferroni校正26组合 | 校正后Wilson下界≥50% | P1 |

**V04执行方案：**
```
当前问题：115-130区间WR下降（违反单调性）
根因：BB宽度+成交量在高分区间反向（高波动=已爆发=反转）
修复：115~130区间加入共振点加权
  - 共振3 → 额外+10分（推开死亡区间130-145）
  - 共振2 → 额外+5分
  - 无共振 → 不放行（已有门控）
预期：115~130段WR从27.8%提升到50%+
```

**V05执行方案（达摩院19折标准）：**
```
对每一折独立计算IC：
  IC = corr(score, is_win)
  19折中≥15折IC>0 = 通过（稳定性≥79%）
  19折中<10折IC>0 = 评分器无预测力，需重写
```

**V06执行方案：**
```
26个组合同时测试 → Bonferroni校正
  原始α=0.05 → 校正后α=0.0019
  需要z=3.09（不是1.96）
  Wilson 99.9%下界≥50% = 统计显著
  Wilson 99.9%下界<50% = 可能是多重比较偏差
```

### Layer 3: 实战可行性（V07-V09）

|------|--------|------|----------|--------|

| **V08** | 极端事件 | 2022-05 Luna / 2022-11 FTX / 2024-08日元 期间单独统计 | 期间WR≥40% | P1 |
| **V09** | 资金曲线 | 完整NAV轨迹 + 最大连续亏损天数 + Calmar比率 | 最大回撤<15%NAV | P1 |

**V07执行方案（达摩院成本标准）：**
```
在v3回测中加入：
  1. 每笔硬扣0.08%成本（达摩院标准）
  2. entry价格 ±5bp滑点扰动
  3. 入场延迟1根K线（用下一根开盘价 ± 5bp）
  4. exit价格 ±5bp滑点扰动

测试矩阵：
  理想(0bp, 0延迟): WR=55.7% → 基准
  正常(5bp, 1延迟): 估算WR=53~55% → 通过标准
  恶劣(10bp, 2延迟): 估算WR=50~53% → 最低可接受
  极端(20bp, 3延迟): 估算WR=48~50% → 否决线（WR<48%=不可执行）
```

**V08执行方案：**
```
定义极端事件窗口：
  2022-05-01 → 2022-05-31（Luna崩盘）
  2022-11-01 → 2022-11-30（FTX暴雷）
  2024-08-01 → 2024-08-31（日元carry trade unwind）

验证标准：
  期间信号WR≥40% = 通过（极端行情仍能生存）
  期间信号WR<40% = 需要加入极端事件熔断门控
```

**V09执行方案：**
```
完整资金曲线模拟：
  NAV起始 = 100,000U
  单笔仓位 = 5% NAV × 5x杠杆 = 25,000U
  按信号时间顺序逐笔模拟
  统计：最大回撤、最大连续亏损天数、Calmar比率
  
通过标准：
  最大回撤 < 15% NAV = 通过
  最大连续亏损 < 10笔 = 通过
  Calmar > 1.0 = 良好
```

### Layer 4: 泛化鲁棒性（V10-V12）
