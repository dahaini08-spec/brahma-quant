## 1. 体制乘数修复

### 修复前 (brahma_core.py L519)
```python
score = int(score * _regime_mult)  # 体制乘数直接乘score
```

### 修复后
```python
# regime_mult不再乘score，只传给position_sizer作为仓位上限
breakdown['_regime_mult'] = _regime_mult
breakdown['_regime_position_cap'] = _regime_mult  # position_sizer读此字段
```

### 修复根因
- 体制检测用价格EMA趋势判断BULL/BEAR
- 方向信号也用价格结构(OB/FVG)判断做多做空
- 两者信息源重叠 → 乘score = 双重计算
- Phase B铁证: OOS拆分中加权EV(-0.0226%)比等权EV(-0.0189%)更差

## 2. Score分布影响

修复后反推原始score（去除乘数扭曲）:

| Score区间 | 旧(乘后) | 新(原始) | 差值 | 说明 |
|-----------|---------|---------|------|------|
| >=80 | 545 | 362 | -183 | 33%的"及格"信号是乘数吹的 |
| >=100 | 296 | 108 | -188 | 63%的高分是乘数幻觉 |
| >=120 | 112 | 30 | -82 | 73%的"神级"信号是乘数幻觉 |
| >=140 | 45 | 9 | -36 | **80%的"神级"信号是乘数幻觉** |
| >=160 | 9 | 4 | -5 | 56%是幻觉 |

**核心发现**: 旧逻辑下>=140的45个信号中，36个(80%)的原始score只有110-120。这些信号被乘数吹到140+后进入高仓位区间，但结构质量不支持 → 实盘140+区间23SL vs 8TP的根因。
