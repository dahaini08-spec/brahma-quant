# 姓赵不宣 视频系统 — 三方深度融合设计方案
# 2026-09-10 | 梵天设计院

## 三方视角

### 40年交易员视角
- 视频 = 信息传递工具，不是娱乐
- 观众3秒内要看到：标的+方向+入场价
- K线图是核心证据，文字是结论，头像是信任背书
- 6秒太短（参考视频），15-30秒足够传递BTC+ETH完整布局
- 语音用中文，不是英文

### 工程师视角
- HeyGen余额$0 → 口型同步暂不可用
- Edge-TTS免费无限量 → 语音可用
- matplotlib渲染K线 → 一次渲染<2s
- PIL帧合成 → 549帧/3s（v2已验证）
- ffmpeg合并 → <1s
- 全链路 <10s 生成一个视频
- 分层设计：免费层立即可用，HeyGen层充值即升级

### 统计学家视角
- 信息密度 vs 理解速度需要平衡
- 文字逐行展开比一次性全部显示更好（减少认知负载）
- 图表和文字同步出现比先后出现更好（建立视听关联）
- 语音节奏应与文字展开同步（避免视听不同步）
- 15-20秒是最佳时长（足够信息量，不拖沓）

## 融合方案：分层架构

### Layer 1: 免费版（立即可用）
```
输入：梵天分析结果（BTC/ETH K线 + VIP策略）
     ↓
Edge-TTS → 中文语音（YunyangNeural 男声）
     ↓
matplotlib → K线图（带FVG/OB/清算标记）
     ↓
PIL合成 → 头像(静态) + K线 + 策略文字(逐行) + 语音
     ↓
ffmpeg → MP4 (884×480, 24fps, ~15s)
     ↓
输出：可发布到币安Square
```

### Layer 2: HeyGen升级版（充值后）
```
Layer 1基础上：
- 静态头像 → HeyGen API口型同步视频
- 语音同步驱动头像微动
- 其余布局不变
```

### Layer 3: 全自动版（终极形态）
```
cron触发 → 梵天分析 → 文字稿生成 → Layer 2视频 → Square API自动发布
每日2次：UTC01:00 + UTC09:00
```
