## ⑥ SMC画线教学——FVG（65:00-80:00）

今晚教第一个SMC概念：FVG，公允价值缺口。

什么是FVG？价格急速移动时留下的未成交区间。想象一下，价格从75,000突然跳到77,000，中间75,500到76,500没人交易过。这段空白就是FVG。未来价格会像磁铁一样被吸引回来填补。

现在在BTC 4H图上画一个Bear FVG。看这里，77,000到77,324，这是之前下跌时留下的缺口。Bear FVG等于磁铁向下。如果价格反弹到77,000到77,324这个区间，Bear FVG中点77,160就是阻力。

FVG有三个价位，记好了。

下沿，是支撑或阻力位。
中点，是最强阻力。
上沿，是失效边界。

做空的时候，止损放FVG上沿之上。做多的时候，止损放FVG下沿之下。

你们在自己的K线图上找一个FVG，截图发评论，我来看画得对不对。

常见错误：很多人把Bear FVG当支撑用。Bear FVG不是支撑，是磁铁向下。回补Bear FVG等于做空机会，不是做多机会。搞反了就是送钱。

记住：Bull FVG磁铁向上，回补做多。Bear FVG磁铁向下，回补做空。方向不要搞反。
