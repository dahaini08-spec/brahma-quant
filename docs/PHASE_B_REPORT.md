## 1. Walk-Forward + CPCV

### Walk-Forward
- **样本**: 140条已结算信号（2026-07-03 ~ 2026-09-10）
- **结果**: ❌ 无法生成有效折
- **原因**: 数据跨度仅~2.5个月，训练段不足30条已结算信号
- **旧README声称**: WF 19折 OOS WR=82.7%
- **实际**: 连8折都无法支撑，旧数字完全不可复现

### CPCV (Combinatorial Purged Cross-Validation)
- **组合数**: 12（6组×2测试组）
- **PBO**: 41.7%（阈值50%）
- **正EV组合**: 7 | 负EV组合**: 5
- **平均测试EV**: +12.18%
- **判定**: ✅ 非过拟合（PBO < 50%）
- **注意**: 样本极小(n=140)，统计效力有限，PBO=41.7%仅表示"在当前样本下未检测到严重过拟合"

## 3. Block Bootstrap Monte Carlo

### 核心改进 vs 旧mega_mc.py
| 维度 | 旧版 | 新版 |
|------|------|------|
| 采样 | i.i.d.有放回 | block bootstrap (block=6) |
| NAV计算 | 加法 nav += pnl | 乘法 nav *= (1+r) |
| 杠杆 | 无 | 1x/3x/5x/10x/20x扫描 |
| 资金费 | 无 | 0.01%/8h × leverage |
| 爆仓 | nav < 0.7×start | nav <= 0 |

### 结果（主杠杆5x, 50K模拟）

| 指标 | 旧README声称 | Phase B实测 |
|------|-------------|------------|
| P50 NAV | +1,364% ($146,400) | **$680** (-93.2%) |
| P5 NAV | +909% ($100,900) | **$64** (-99.4%) |
| P95 NAV | +1,958% ($205,800) | **$9,072** (-9.3%) |
| Ruin率 | 0.0% | **0.00%** (但中位MaxDD=95.3%) |
| Sharpe P50 | 25.09 | **-2.51** |
| 50%回撤概率 | — | **99.76%** |
| 70%回撤概率 | — | **96.57%** |
| 90%回撤概率 | — | **73.87%** |

### 杠杆扫描

| 杠杆 | P50 NAV | 中位MaxDD | 50%回撤概率 |
|------|---------|---------|------------|
| 1x | $6,222 (-37.8%) | 43.6% | 31.2% |
| 3x | $2,178 (-78.2%) | 83.1% | 96.7% |
| **5x** | **$680 (-93.2%)** | **95.3%** | **99.8%** |

**结论**: 用真实成本后收益 + 乘法复利 + 杠杆，P50终点是巨亏。旧版MC P50 +1364%完全是加法bootstrap + 无杠杆的假象。

## 4. 体制×方向信息隔离

### 信息重叠检测

| 指标 | 值 | 解读 |
|------|-----|------|
| NMI(体制, 方向) | 0.066 | 低重叠 → 看似独立 |
| NMI(体制, 结果) | 0.092 | 弱预测力 |
| NMI(方向, 结果) | 0.006 | 方向几乎无预测力 |
| 条件MI(体制\|方向) | 0.033 | 体制有增量信息 |

### 乘数效果对比

| 场景 | 加权EV | 等权EV | 乘数更优 |
|------|--------|--------|---------|
| 全样本 | -0.0471% | -0.0378% | ❌ 否 |
| OOS前半训练/后半测试 | -0.0226% | -0.0189% | ❌ 否 |

**乘数在OOS上表现更差** — 证实审计假设：体制乘数放大了噪声。

### 6.5年回测大样本

| 方向 | 乘数放大正确 | 乘数放大错误 | 准确率 |
|------|------------|------------|--------|
| 全部 | 6 | 2 | 75% |

回测大样本（47K条）中，乘数放大方向有75%准确率 — 但实盘OOS拆分显示乘数加权反而更差。这说明回测中的"正确"存在前视偏差。

| 审计项 | 旧README声称 | Phase B实测 | 判定 |

## 关键发现

1. **DSR=-16.92**：样本夏普本身是负的（-2.15），说明当前实盘信号在成本后是亏损的。旧DSR=22.64不可能从这组数据复现。

2. **MC P50=$680（起始$10,000）**：乘法复利+真实杠杆+资金费后，5x杠杆中位终点是亏93%。旧版加法bootstrap+无杠杆产生+1364%是数学幻觉。

3. **体制乘数OOS无效**：OOS拆分中加权EV比等权EV更差，证实审计假设——体制检测和方向信号用相同的价格趋势信息，乘数是双重计算。

4. **CPCV是唯一通过的**：PBO=41.7%<50%，但这仅表示"当前样本未检测到严重过拟合"，样本量n=140统计效力弱。

## 下一步建议

Phase B验证结果指向一个明确结论：**当前系统的核心问题是信号质量，不是验证方法**。

- DSR=-16.92 → 信号在成本后亏损
- MC P50=-93% → 5x杠杆下几乎归零
- 体制乘数OOS无效 → 双重计算确认

Phase C建议：
1. 不再优化验证方法（已经够好）
2. 转向信号质量提升：改进score维度、减少噪声信号、提高score与结果的IC
3. 或者诚实接受当前系统的研究阶段定位，不做实盘
