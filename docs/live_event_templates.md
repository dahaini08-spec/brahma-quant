# 🎯 事件直播预案模板（3套）

> FOMC / CPI / NFP 各一套，120分钟事件版直播使用

---

## 模板A：FOMC（联邦公开市场委员会）

### 前置准备
- 读取上次FOMC纪要关键词
- CME FedWatch降息概率
- BTC/ETH当前位置+体制状态
- 清算地图：上方止损墙/下方支撑池

### 00-10min：开场定调

```
"今晚FOMC，我给你三种剧本。"
"不是猜涨跌，是提前想好每种情况怎么操作。"

剧本1：鸽派（降息25bp + 鸽派声明）
→ 风险资产上涨，BTC冲止损墙，ETH弹性更大
→ 操作：等数据公布后15分钟，回踩FVG中点做多

剧本2：鹰派（不降息或鹰派声明）
→ 风险资产下跌，BTC打支撑池
→ 操作：等数据公布后15分钟，反弹到OB做空

剧本3：中性（降息25bp + 中性声明）
→ 波动率放大但无方向，V型反转
→ 操作：不做，等第二天确认方向

互动："你赌鸽派还是鹰派？弹幕打1或2"
```

### 10-30min：数据直播

```
"数据出来了，我先念数字，你再反应。"
逐项解读：
- 基准利率：X% → 预期X% → 符合/超预期
- 声明措辞变化：删了什么 / 加了什么
- 点阵图（如有）：降息路径 vs 市场预期
- 鲍威尔发言（如有）：关键词解读

互动："现在弹幕刷多还是空？"
```

### 30-50min：结构分析

```
"数据看完了，现在看结构变了没有。"
投屏K线画线：
- 数据公布后是否形成新FVG？
- 前高/前低是否被突破？
- OI是增还是减？（资金跟进还是撤资？）
- CVD方向？
```

### 50-70min：操作方案

```
"现在说操作。不是建议，是我的计划。"
- 如果鸽派+结构确认做多：入场区X-X，止损X，目标X→X→X
- 如果鹰派+结构确认做空：入场区X-X，止损X，目标X→X→X
- 如果中性+结构不确认：不做，明天再看

互动："你会追吗？弹幕说追还是等"
```

### 70-85min：历史复盘

```
"上次FOMC你赚了还是亏了？"
HCME同类事件：
- 上次鸽派FOMC：BTC反应+X%，WR=X%
- 上次鹰派FOMC：BTC反应-X%，WR=X%
- 共性规律：数据公布后1H收阳/收阴 = 当晚方向
```

### 85-100min：互动问答

```
优先回答高赞问题
关注：仓位管理 / 止损设置 / 杠杆选择
```

### 100-115min：画线验证

```
投屏画线：数据公布后的新结构
- 新FVG在哪？磁铁往哪拉？
- OB是否还有效？
- 清算地图是否变化？
```

### 115-120min：收盘

```
"今晚FOMC方向确认：偏X"
"明天关注X价位，破X追X，破X反X"
互动："明天BTC收阳还是收阴？投票"
```

## 模板B：CPI（消费者价格指数）

### 前置准备
- 上次CPI数据 + 市场预期
- 核心CPI vs 整体CPI
- 通胀趋势：上升/下降/持平
- BTC/ETH清算地图

### 00-10min：开场定调

```
"今晚CPI，通胀数据是美联储的指南针。"
"三个数字决定今晚方向：CPI YoY、Core CPI YoY、CPI MoM。"

剧本1：Hot（通胀超预期）
→ 降息预期下降，风险资产下跌
→ 操作：反弹做空，止损前高上方

剧本2：Cool（通胀低于预期）
→ 降息预期上升，风险资产上涨
→ 操作：回踩做多，止损前低下方

剧本3：In-line（符合预期）
→ 市场按既定方向走，波动率短暂放大后回归
→ 操作：不做，等FOMC

互动："你觉得CPI会Hot还是Cool？弹幕打1或2"
```

### 10-30min：数据直播

```
逐项解读：
- CPI YoY：X% vs 预期X% → 偏热/偏冷/符合
- Core CPI YoY：X% vs 预期X% → 关键！
- CPI MoM：X% vs 预期X%
- 实际利率 = 名义利率 - CPI → 正还是负？

"Core CPI才是真正影响市场的数字。整体CPI可以被能源/食品扭曲。"
```

### 30-50min：结构分析

```
- 数据公布后BTC/ETH的15分钟K线形态
- 是否形成新FVG？
- OI：资金跟进还是撤资？
- FR：是否出现极端值？
```

### 50-70min：操作方案

```
- Cool+结构确认做多：入场区，止损，目标
- Hot+结构确认做空：入场区，止损，目标
- In-line：观望，等FOMC

"CPI后做单，止损必须放在数据公布时的高点/低点之外。"
```

### 70-85min：历史复盘

```
HCME同类CPI事件：
- 上次Cool CPI：BTC +X%，但X小时后回吐X%
- 上次Hot CPI：BTC -X%，但X小时后反弹X%
- 规律：CPI影响通常持续24-48小时
```

### 85-120min：互动+画线+收盘

同FOMC模板

## 模板C：NFP（非农就业数据）

### 前置准备
- 上次NFP + 预期
- 失业率 vs 就业人数
- 平均时薪（工资通胀指标）
- BTC/ETH清算地图

### 00-10min：开场定调

```
"NFP是就业数据，但交易员看的不是就业，看的是美联储会不会因为就业强而推迟降息。"

剧本1：强就业（新增就业 > 预期）
→ 美联储有空间维持高利率，风险资产下跌
→ 操作：反弹做空

剧本2：弱就业（新增就业 < 预期）
→ 美联储被迫降息，风险资产上涨
→ 操作：回踩做多

剧本3：符合预期
→ 波动有限，方向看现有结构

互动："你觉得就业强还是弱？投票"
```

### 10-30min：数据直播

```
逐项解读：
- 非农新增：X万 vs 预期X万
- 失业率：X% vs 预期X%
- 平均时薪YoY：X% vs 预期X% → 工资通胀
- 修正值：上月数据是否大幅修正？

"NFP的修正值经常比本期数据更重要。上月从10万修正到5万，比这个月15万更重要。"
```

### 30-50min：结构分析 + 50-70min：操作方案 + 70-85min：历史复盘 + 85-120min：互动+收盘

同FOMC模板，替换为NFP相关数据
