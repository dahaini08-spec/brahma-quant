## 🔧 重设计验证链路（5层）

### Layer 1: 生产评分器验证（修复问题1）

**问题：** 回测用score_v4，生产用confluence_score，两者无关。

**方案：** 写一个生产评分器适配层，让回测直接调用confluence_score。

```python
# scripts/dharma_prod_validator.py
# 用真实confluence_score跑4.5年回测
# 需要构造ms/smc字典格式，适配生产评分器接口
```

**验证标准：**
- 生产评分器IC > 0（不要求+0.0150，但必须正）
- 生产评分器WR ≥ 48%（扣成本前）
- 如果IC为负 → 手术无效，需要回滚

### Layer 2: 样本外验证（修复问题2）

**问题：** 砍维度和验证用同一份数据。

**方案：** 时间切分验证。

```
训练集：2022-01-01 ~ 2024-12-31（3年）
  → 在训练集上算IC，确定保留哪些维度

测试集：2025-01-01 ~ 2026-09-09（1.75年）
  → 用固定维度集合，在测试集上算IC
  → 如果测试集IC仍>0 → 真alpha
  → 如果测试集IC≤0 → 过拟合，需要回滚
```

**验证标准：**
- 测试集IC > 0
- 测试集net EV > -0.03%（允许略差，但不能太差）

### Layer 3: WF稳定性标准（修复问题3）

**问题：** WF=0%但被忽略。

**方案：** WF稳定性纳入硬通过标准。

```
通过标准（全部必须满足）：
  1. net EV > 0
  2. WF稳定性 ≥ 60%（9折中至少5折WR≥52%）
  3. 单折最大亏损 < 0.15%/笔
  4. Sharpe > 0.5

当前状态：WF=0% → 不通过
```

**如果WF不通过：**
- 不上线
- 尝试改变变量（RR/出场/min_score）直到WF通过
- 如果所有配置WF都不通过 → 策略本身有问题，需要重新设计

### Layer 4: 入场质量过滤器（修复问题4+5）

**问题：** OB/FVG/清算从评分器砍掉，但入场点和SL依赖它们。

**方案：** 评分器和入场过滤器分离。

```
评分器（已完成手术）：
  → 只用12个正IC维度评分
  → 决定"这个信号好不好"

入场过滤器（新增）：
  → 不参与评分，但参与入场门控
  → 决定"这个入场点安不安全"

过滤器规则：
  Filter 1: OB有效性
    if not valid_ob: 不入场
    
  Filter 2: FVG方向一致
    if signal_dir==LONG and fvg_type!=bull: 不入场
    if signal_dir==SHORT and fvg_type!=bear: 不入场
    
  Filter 3: 清算密集区
    liq_dist = 距最近清算密集区的距离
    if liq_dist < 0.5*ATR1H: 不入场
    if liq_dist < 1.0*ATR1H: 仓位×0.5
```

**验证：** 对比有过滤器vs无过滤器的WR/EV差异。

### Layer 5: 结构感知出场（修复问题6）

**问题：** 精简评分器+浮盈保护=灾难（WR 49.8%→32.9%）。

**方案：** 不用固定ATR倍数浮盈保护，改用结构感知出场。

```
当前（有问题）：
  浮盈 > 2.5×ATR → SL移到入场价（保本）
  → 精简评分器没有结构信息，一碰就跑

改为：
  出场信号1: TP触达（固定RR，不变）
  出场信号2: OB失效（结构驱动）
    if signal_dir==LONG and price < valid_ob_bottom: 出场
    if signal_dir==SHORT and price > valid_ob_top: 出场
  出场信号3: 时间止损（体制自适应）
    BULL/BEAR_TREND: 36根K线
    CHOP: 12根K线
  出场信号4: trailing SL（仅在大利润时）
    浮盈 > 4×ATR → SL移到入场+2×ATR（锁定利润，不是保本）
    浮盈 > 8×ATR → SL移到入场+5×ATR（让利润奔跑）
  
  去掉：浮盈>2.5×ATR保本（这个是灾难根源）
```

**验证：** 对比5种出场方式的WR/EV：
1. 无浮盈（自然SL/TP）
2. 2.5×ATR保本（原版，已知灾难）
3. trailing SL（仅大利润）
4. 结构感知（OB失效出场）
5. 结构感知+trailing SL

## ⚠️ 设计原则（三方共识）

1. **回测=生产** — 验证必须用真实评分器，不允许用简化版
2. **样本内外分离** — 训练集定参数，测试集验证
3. **WF是硬标准** — net EV>0但WF=0% = 不通过
4. **评分与过滤分离** — 评分器判断信号质量，过滤器判断入场安全
5. **出场必须结构感知** — 不用固定ATR倍数，用结构驱动出场
