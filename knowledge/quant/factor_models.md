## 一、经典因子模型

### Fama-French 三因子模型
```
E(R) - Rf = β×(Rm-Rf) + s×SMB + h×HML

Rm-Rf：市场风险溢价
SMB：小市值溢价（Small Minus Big）
HML：价值溢价（High Minus Low 账面市值比）
```
**加密映射：** 市值因子在加密市场有效（小市值山寨相对BTC的超额收益）

### Carhart 四因子（动量因子）
```
新增 MOM：动量因子（过去12个月收益率减去最近1个月）
```
**加密实证：** 动量因子在加密市场极强（WR=65%+），是梵天score的核心维度之一

### 五因子模型（Fama-French 2015）
```
新增：RMW（盈利能力）+ CMA（投资激进度）
加密映射：链上盈利能力指标（MVRV, NVT）替代RMW
```

## 二、加密专用量化因子

### 动量因子（Momentum）
- **定义：** 过去N天收益率
- **加密实证：** 7日/30日/90日动量均有效
- **梵天应用：** score中的趋势动量维度
- **注意：** 在极端行情（±30%以上）动量因子失效，需结合体制过滤

### 波动率因子（Volatility）
- **低波动溢价：** 低波动率资产长期超额收益（与传统市场相反，加密市场高波动溢价）
- **梵天应用：** ATR/BBW是波动率因子的代理变量
- **规则：** 高波动期降仓（MAX_SL_PCT_HIGH_VOL=9%），低波动方仓埋伏

### 流动性因子（Liquidity）
- **Amihud非流动性指标：** |收益率|/成交量
- **加密应用：** 低流动性山寨在上涨时涨幅更大（流动性溢价）
- **梵天规则：** EXECUTOR_BLACKLIST包含低流动性标的，避免滑点

### 链上因子（On-chain）
- **MVRV（市值/已实现价值）：** >3.5 = 历史顶部区；<1 = 历史底部区
- **NVT（网络价值/交易量）：** 高NVT = 估值过高；低NVT = 低估
- **SOPR（消费输出盈利率）：** >1 = 多数持仓盈利；<1 = 多数持仓亏损
- **梵天集成：** 链上维度是35维评分的Block B（维度7-10）

### 情绪因子（Sentiment）
- **社交媒体情绪：** Twitter/Reddit提及量 + 情绪极性
- **谷歌搜索量：** BTC搜索热度与价格正相关（但滞后）
- **梵天应用：** narrative_engine情绪评分 + 极端事件预警

## 三、统计套利方法论

### 配对交易（Pairs Trading）
```
选择高相关币对（如BTC/ETH相关系数>0.8）
计算价差的z-score：z = (spread - mean) / std
z > 2 → 做空价差（做空强势，做多弱势）
z < -2 → 做多价差
```
**加密限制：** 高相关性在极端行情下会突然崩溃，需严格止损

### 均值回归（Mean Reversion）
- **适用体制：** CHOP_MID（梵天实测WR=17-27%，负EV，目前全封禁）
- **布林带策略：** 价格触上轨做空，触下轨做多（在区间内有效）
- **梵天结论：** 均值回归在加密市场效果差于趋势跟踪，故CHOP体制不做

### 趋势跟踪（Trend Following）
- **适用体制：** BULL_TREND / BEAR_TREND
- **梵天铁证：** BULL_TREND LONG WR=45.5%（n=162），BEAR_TREND SHORT WR=69-87%
- **核心规则：** 顺体制方向，等待回撤到OB/FVG区入场，不追市价

## 四、风险管理模型

### VaR（风险价值）
```
VaR(95%) = 单日最大亏损（95%置信度下不超过此值）
加密日VaR通常3-8%（远高于传统资产0.5-1%）
```
**梵天实现：** 单笔最大亏损=NAV×2%，相当于对个仓设置VaR上限

### Kelly公式（凯利准则）
```
f* = (WR × RR - (1-WR)) / RR
其中：f*=仓位比例，WR=胜率，RR=盈亏比
```
**梵天简化版：**
- WR=100%（BEAR_RECOVERY铁证）→ 5%NAV（保守，避免过拟合）
- WR=45%（BULL_TREND LONG）→ 0%（负EV，不开）
- 实践：凯利值×0.25~0.5（半凯利），更安全

### 最大回撤控制
- **目标：** 月度最大回撤<15%
- **梵天机制：** position_sl_state.json追踪持仓；circuit_breaker.py触发熔断
- **熔断规则：** 当日亏损>NAV×5% → 暂停新开仓24H

## 五、机器学习在量化中的应用

### 时序预测（梵天已集成）
- **HAR-RV：** 异质自回归已实现波动率，预测未来波动
- **Hurst指数：** 长记忆性检验，判断趋势持续性
- **LSTM/Transformer：** 价格预测（梵天评估后未集成，过拟合风险高）

### 强化学习（RL）
- **理论：** Agent与市场环境交互，最大化累计收益
- **实践问题：** 加密市场非平稳，RL策略在实盘中过拟合严重
- **梵天结论：** WR矩阵+规则系统 > 纯RL（在小数据量情况下）

### 特征工程最佳实践
- **时序特征：** 收益率、波动率、成交量的多周期统计量
- **交叉特征：** OI×价格变化；资金费率×成交量
- **梵天35维：** 已是经过验证的特征工程体系，不轻易增删维度

## 六、回测方法论

### 常见回测陷阱
1. **前视偏差（Look-ahead Bias）：** 用未来数据计算当前信号 → 梵天避免方式：严格时间戳管理
2. **幸存者偏差：** 只用当前存活的标的回测 → 梵天避免：包含退市/低流动性标的记录
3. **过拟合：** 参数针对历史数据优化 → 梵天避免：OOS验证+simfactory 64条测试
4. **交易成本忽视：** 不计手续费和滑点 → 梵天：真实WR比回测低3-5%（封印在MEMORY）

### 梵天回测标准
- **最小样本：** n≥10才算铁证，n<10仅供参考
- **时间跨度：** 6.8年历史数据（覆盖牛熊完整周期）
- **验证方式：** simfactory压力测试 + 纸面实盘验证
- **上线门槛：** OOS WR与回测WR偏差<10%才封印到WR矩阵
