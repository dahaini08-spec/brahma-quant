## 一、趋势类指标

### EMA / SMA（指数/简单移动均线）
- **参数：** EMA(9), EMA(21), EMA(50), EMA(200)
- **梵天用法：** EMA9/21交叉 = 短期动量信号；价格在EMA200上方 = BULL_TREND确认
- **铁证：** EMA50>EMA200（金叉）持续时间 × 斜率 → 体制强度评分维度之一
- **死穴：** 震荡行情EMA频繁交叉 → 假信号率>60%，CHOP体制下降权

### MACD（移动平均收敛散度）
- **参数：** 12/26/9（标准）；梵天用4H/1D双周期
- **梵天用法：** MACD柱由负转正 = 动量反转信号；histogram斜率 > 体制方向验证
- **关键规则：** MACD背离（价格创新高但MACD不创新高）= CHoCH预警
- **与体制结合：** BULL_TREND中MACD持续在0轴上方 → 强趋势确认+3分

### ADX（平均趋势指数）
- **参数：** 周期14，阈值：<20=无趋势，20-40=趋势初成，>40=强趋势
- **梵天用法：** ADX>25 → 允许趋势跟踪策略；ADX<20 → 切换至震荡策略
- **体制映射：** ADX>40 = BULL_TREND/BEAR_TREND强化信号；ADX<20 = CHOP_MID

## 二、震荡类指标

### RSI（相对强弱指数）
- **参数：** 周期14；超买>70，超卖<30；梵天极值：>65做空，<35做多
- **梵天铁证：** RSI_4H + RSI_1H + RSI_1D三周期共振
  - 三重超卖(1H<35+4H<45+1D<55) → score+15
  - 双重超卖(1H<35+4H<45) → score+8
  - 逆流信号 → score-5
- **分层数据：** RSI>65做多突破率24.4%；RSI<35做空突破率27.5%（535条6.8年铁证）

### Bollinger Bands（布林带）
- **参数：** SMA20 ± 2σ；BBW = (上轨-下轨)/中轨×100
- **梵天核心用法：** BBW压缩 = 方仓形态识别
  - BBW<3% → P1豁免（绕过score门槛直接走战场预判）
  - BBW<5% → 纸面开单自动扫描触发
- **方仓铁证：** 低BBW+低range+RSI中性 = 方仓压缩→突破概率高
- **布林挤压：** BB带宽收窄到近6个月最低10% = 大行情前兆

### Stochastic RSI
- **参数：** 14/3/3；超买>80，超卖<20
- **梵天用法：** StochRSI与RSI双重确认；极值区域+OB结构 = 高概率入场区

### Williams %R
- **参数：** 周期14；-80以下超卖，-20以上超买
- **梵天用法：** 与RSI互补，在RSI信号模糊时辅助判断

## 三、波动率类指标

### ATR（平均真实波动范围）
- **参数：** 周期14；梵天用ATR4H作为基准
- **梵天铁律（止损计算核心）：**
  - SL距离必须 ≥ 1.5×ATR4H，否则止损不合理
  - 绝对禁止：用ATR×小乘数（如0.28）计算止损 → 产生噪音级止损
- **波动率分层：** ATR/Price > 0.03 = 高波动；< 0.01 = 低波动（方仓区间）

### VIX / BVIV（恐慌指数）
- **VIX：** 美股恐慌指数，>30 = 市场恐慌，<15 = 市场贪婪
- **BVIV（BTC波动率）：** BTC期权隐含波动率
- **梵天用法：** VIX>30时BTC相关性与美股上升 → 宏观风险叠加，降仓
- **与FG结合：** FG<25（极度恐慌）+ VIX<20 = 市场分化，关注BTC独立行情

### HAR-RV（异质自回归已实现波动率）
- **梵天集成：** 已替代Kronos的torch依赖，用日内/日/周三层RV预测未来波动
- **用法：** HAR-RV预测值 > 历史均值1.5倍 → 波动率扩张预警，信号门槛提升

## 四、成交量类指标

### OBV（能量潮）
- **公式：** OBV = 累计（上涨日成交量 - 下跌日成交量）
- **梵天用法：** OBV创新高但价格未创新高 = 量价背离 = 突破确认
- **体制强化：** BULL_TREND中OBV持续上升 → 趋势有量支撑，+2分

### VWAP（成交量加权平均价）
- **梵天用法：** 机构日内基准价格；价格回测VWAP = 高概率支撑/阻力
- **SMC结合：** OB区间 + VWAP重叠 = 机构布局区强化

### CVD（累计成交量差）
- **公式：** 主动买入量 - 主动卖出量的累计
- **梵天用法：** CVD与价格背离 = 主力方向判断；OI上升+CVD下降 = 多头建仓被空头压制

## 五、链上/衍生品专用指标

### OI（未平仓合约）
- **梵天核心维度：** OI变化率是35维评分中的独立维度
- **规则：**
  - OI上升+价格上升 = 多头主导，趋势强
  - OI上升+价格下降 = 空头建仓，趋势强
  - OI下降+价格变动 = 平仓行为，趋势弱
- **oi_advanced_scanner：** 扫描OI异常标的 → 写入oi_advanced_signals.jsonl

### Funding Rate（资金费率）
- **正常范围：** -0.01% ~ +0.01%（8H）
- **梵天规则：**
  - 资金费率持续>+0.1% = 多头过度拥挤 = 做空加分
  - 资金费率持续<-0.05% = 空头过度拥挤 = 做多加分
  - 极端费率+价格在关键区 = 强化信号

### Liquidation Heatmap（清算热力图）
- **梵天集成：** liq_density_engine 扫描三所清算数据
- **核心逻辑：** 清算层 = 流动性猎杀目标；价格会优先向清算密集区运动
- **liq_bonus：** 清算顺势+5分 → auto_executor动态降低门槛至150

### Long/Short Ratio（多空比）
- **梵天用法：** L/S>2.0 = 多头过度拥挤；L/S<0.5 = 空头过度拥挤
- **反向指标：** 极端多空比往往预示反转，与FG结合使用

## 六、市场结构指标（SMC体系）

### BOS（Break of Structure）
- **定义：** 价格突破前一个摆动高/低点 = 趋势方向确认
- **梵天用法：** BOS确认后，等待回撤到OB区间入场
- **注意：** BOS需要收盘价确认，影线触及不算

### CHoCH（Change of Character）
- **定义：** 在下跌趋势中，价格首次突破前一个摆动高点 = 趋势反转信号
- **梵天用法：** CHoCH + 15M确认 → trigger_15m.py触发入场
- **P5修复：** CHoCH未confirmed → +15分（原+5），触发阈值50（原55），触发率55%→75%

### OB（Order Block）
- **定义：** 机构在此处大量建仓的K线区间；最后一根相反方向K线
- **梵天识别：** 做多OB = 下跌前的最后一根阳线区间；做空OB = 上涨前的最后一根阴线区间
- **有效性：** OB被价格回测且未被完全穿越 = 有效；被穿越 = 失效

### FVG（Fair Value Gap）
- **定义：** 三根K线中，第一根高点与第三根低点之间的空白区（做多FVG）
- **梵天用法：** 价格回填FVG = 高概率反应位；FVG + OB重叠 = 强信号区

## 七、宏观关联指标

### DXY（美元指数）
- **与BTC关系：** DXY上涨通常 → BTC承压；DXY下跌 → BTC受益
- **梵天宏观层：** DXY日线趋势是MacroAgent的核心输入之一
- **关键位：** DXY>105 = 强势美元，加密承压；DXY<100 = 弱势美元，加密利好

### 美债收益率（US10Y）
- **逻辑：** 收益率上升 → 风险资产折现率上升 → 加密承压
- **关键位：** US10Y>4.5% = 高利率环境，风险偏好下降

### Fear & Greed Index（恐惧贪婪指数）
- **范围：** 0-100；0-25极度恐慌，75-100极度贪婪
- **梵天规则：**
  - FG<25 + BTC.D下降 = 山寨季启动信号
  - FG>75 + OI高位 = 顶部区域预警
  - 极度恐慌时BEAR_RECOVERY信号权重上升

## 八、梵天独有指标

### Hurst指数
- **定义：** 0.5=随机游走；>0.5=趋势持续；<0.5=均值回归
- **梵天用法：** Hurst>0.6 = 趋势体制确认；Hurst<0.45 = CHOP体制确认
- **与ADX结合：** Hurst>0.6 + ADX>25 = 双重趋势确认

### PIPs几何形态（第9维）
- **定义：** Perceptually Important Points，价格序列中的感知重要拐点
- **梵天用法：** 识别头肩顶/底、三角形、旗形等经典形态
- **评分：** 形态确认 → score±5-10分

### 方仓BBW向量
- **梵天核心：** 6.8年历史方仓案例，BTC=255条 / ETH=280条
- **字段：** compress_bars/bbw_min/range_pct/volume_trend/rsi_at_end
- **检索：** Qdrant语义搜索，当前市场结构匹配历史最相似案例
