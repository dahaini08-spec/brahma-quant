## 一、美联储政策框架

### 利率决策逻辑
```
通胀(CPI/PCE) > 2% 目标 → 加息 → 美元走强 → 风险资产承压
失业率 > 4.5% → 降息预期 → 美元走弱 → 风险资产受益
双重使命：价格稳定 + 充分就业（相互制约）
```

### 关键数据日历（每月影响加密市场）
| 数据 | 发布时间 | 影响程度 | 梵天应对 |
|------|---------|---------|---------|
| CPI | 每月第2周三 | ⭐⭐⭐⭐⭐ | 发布前1H信号暂停 |
| NFP（非农） | 每月第1周五 | ⭐⭐⭐⭐ | 发布前收窄仓位 |
| FOMC会议 | 每6周一次 | ⭐⭐⭐⭐⭐ | 会议日禁止新开仓 |
| PCE | 每月末 | ⭐⭐⭐⭐ | 关注核心PCE |
| GDP | 每季度 | ⭐⭐⭐ | 季度初体制重评估 |

### 美联储政策对体制影响
- **加息周期：** BEAR_TREND概率+15%，BTC/ETH相关性与纳指上升至0.7+
- **降息周期：** BULL_TREND概率+20%，风险资产同涨
- **暂停期：** 体制分化，关注BTC.D判断资金流向

## 二、全球流动性框架

### M2货币供应量
- **逻辑：** 全球M2扩张 → 更多资金寻找收益 → 加密受益
- **关键指标：** 美国M2 + 中国M2 + 欧元区M2同比增速
- **梵天映射：** 全球M2同比>5% → BULL_TREND概率提升

### 美元流动性指标
```
美元流动性 = 美联储资产负债表 - TGA账户余额 - 逆回购余额
流动性上升 → 风险资产上涨
流动性下降 → 风险资产承压
```

### 比特币与全球流动性相关性
- **3个月滚动相关系数：** 通常0.6-0.8（高相关）
- **背离信号：** 流动性上升但BTC不涨 = 做多机会；流动性下降但BTC不跌 = 强势信号

## 四、宏观周期框架

### 加密市场四年周期（比特币减半驱动）
```
减半前6个月：积累期 → BEAR_RECOVERY体制概率高
减半后0-12个月：牛市初期 → BULL_EARLY → BULL_TREND
减半后12-24个月：牛市高峰 → BULL_TREND（score≥140慎重）
减半后24-36个月：熊市过渡 → BEAR_EARLY → BEAR_TREND
减半后36-48个月：熊市底部 → BEAR_TREND → BEAR_RECOVERY
```

### 当前周期定位（2026-08-27）
- 2024年4月第四次减半已过26个月
- 理论上处于牛市高峰→过渡区间
- 梵天体制判断优先，周期仅作背景参考

### Wyckoff市场结构
```
积累区（Accumulation）→ 机构吸筹，价格横盘
上升趋势（Markup）→ 价格上涨，量能扩大
派发区（Distribution）→ 机构出货，价格横盘高位
下降趋势（Markdown）→ 价格下跌
```
- **梵天映射：** 积累区≈CHOP_MID+BEAR_RECOVERY；上升趋势≈BULL_TREND

## 五、机构资金流向指标

### ETF资金流
- **BTC现货ETF：** 每日申购/赎回数据 → 机构净流向
- **规则：** 连续5日净流入>$5亿 → BULL_TREND加强信号
- **来源：** Farside Investors, Bloomberg

### 交易所净流量
- **净流出（交易所→冷钱包）：** 持币意愿强，供应减少，看涨
- **净流入（冷钱包→交易所）：** 准备出售，供应增加，看跌
- **梵天应用：** 链上维度之一，大额净流出+价格在低位 = 强看涨信号

### 稳定币供应量
- **USDT+USDC总供应增加：** 等待入场的资金增加，潜在买盘
- **稳定币供应/BTC市值：** 比值>0.15 = 足够的侧边资金待入场

## 六、地缘政治与监管风险

### 对加密影响的历史规律
- **战争/地缘冲突：** 短期下跌（1-7天），随后恢复（避险→风险资产分化）
- **监管打压：** 中国禁令等 → 短期-20%~-30%，随后适应
- **ETF/监管利好：** 短期+10%~+20%，长期结构性利好

### 梵天应对规则
- 重大地缘事件发生：叙事层触发CRITICAL预警
- 不因单一事件调整体制判断
- 等待WR矩阵吸收事件后的统计数据再更新
