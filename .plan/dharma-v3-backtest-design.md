## 二、全球顶级量化系统回测方法论（借鉴）

### 2.1 Renaissance Technologies（文艺复兴）
- **核心原则**: 所有信号必须经过统计显著性检验（p<0.05）
- **关键方法**: 走步向前（Walk-Forward），训练窗口滑动，不用全样本优化
- **借鉴点**: 梵天的参数（SL/TP/HOLD）必须在训练期确定，绝不用测试期数据调参

### 2.2 Two Sigma（双西格玛）
- **核心原则**: 每个因子单独验证IC（信息系数），IC>0.05才入组合
- **关键方法**: 因子正交化（PCA），防止相关因子虚增权重
- **借鉴点**: 梵天35维中RSI出现4次（s3/s24/s25/timing），等于给RSI4倍权重，必须修正

### 2.3 DE Shaw（肖氏）
- **核心原则**: 所有策略必须通过"压力测试"（极端行情：2020/3、2022/5）
- **关键方法**: 分段验证 = 牛市/熊市/震荡市分开统计WR
- **借鉴点**: 不能只看全样本WR，必须分体制验证

### 2.4 Citadel（城堡）
- **核心原则**: 回测必须包含真实交易成本（滑点+手续费+市场冲击）
- **关键方法**: 期货Taker成本0.05%，Maker成本0.02%，必须计入EV
- **借鉴点**: 梵天目前EV计算没有扣除0.04%~0.08%手续费，所有正EV结论需打折

### 2.5 AQR（对冲基金）
- **核心原则**: 因子必须在多市场（跨资产）验证，单币验证不可信
- **关键方法**: 47个币是独立验证，找"跨币稳健"的组合才是真制胜密码
- **借鉴点**: 只在BTC有效的信号可能是BTC特有噪音，需要ETH/SOL同时验证

## 五、严谨回测框架：核心设计原则

### 5.1 零上帝视角铁律（最重要）

```python
# ❌ 错误：用当根K线最高价/最低价作为信号条件
if klines[i][2] > prev_high:  # 用了i时刻的high
    signal = True

# ✅ 正确：信号只能用i-1时刻（已收盘）的数据
if klines[i-1][4] > prev_high:  # 用前一根收盘价
    signal = True

# ❌ 错误：入场用当根K线的价格范围
entry = klines[i][3]  # 当根最低价（未来才知道）

# ✅ 正确：入场=信号K线收盘价（信号确认后的第一个可成交价）
entry = klines[i][4]  # 收盘价入场（保守，实际可能更好）
```

### 5.2 动态出场（区别于固定HOLD）

```
三种出场条件（满足任一即出场）：
  1. 止损: 价格触及SL（后续K线low触及，做多；high触及，做空）
  2. 止盈: 价格触及TP
  3. 结构失效: 做多后出现BOS空头突破；做空后出现BOS多头突破
  4. 超时保险: 最多持仓MAX_HOLD根（防止资金长期占用）
  
参数选择原则：
  SL = 信号K线ATR × 1.5（与信号强度匹配，不是固定2%）
  TP = SL × RR（RR根据历史WR定：WR=55%需RR≥1.5，WR=60%需RR≥1.0）
```

### 5.3 Walk-Forward验证（防过拟合）

```
标准走步法：
  训练窗口: 2年数据
  测试窗口: 6个月数据（盲测，结果不参与参数调整）
  滑动步长: 3个月
  
  示意：
  [2019-11 ~ 2021-11训练] → [2022-05测试] → 记录
  [2020-05 ~ 2022-05训练] → [2022-11测试] → 记录
  [2020-11 ~ 2022-11训练] → [2023-05测试] → 记录
  ...共12次滚动
  
  最终WR = 12次测试期WR的平均值（这才是真实WR）
  稳定性 = 12次测试期WR的标准差（越小越稳健）
```

### 5.4 分体制统计（DE Shaw方法）

```
每个信号必须分体制统计：
  BULL_TREND期间 WR = ?
  BEAR_TREND期间 WR = ?
  CHOP_MID期间   WR = ?
  
原因：一个信号在牛市WR=70%，熊市WR=30%，全样本=50%
     全样本WR=50%看起来无效，但分开用有巨大价值
```

### 5.5 真实交易成本（Citadel方法）

```
每笔交易扣除：
  Taker手续费: 0.05%（市价单）
  Maker手续费: 0.02%（限价单，可争取）
  滑点估算: 0.03%（市场冲击，大仓位更高）
  资金费率: ±0.01% × 持仓小时数（做多付，做空收）
  
实际EV门槛：
  原始EV > 0.1%/笔 才是真正正EV
  （扣除手续费0.05% + 滑点0.03% + 预期意外0.02%）
```

### 5.6 多币跨市场验证（AQR方法）

```
有效信号必须：
  在BTC验证 AND ETH验证 AND 至少3个山寨币验证
  3个市场中至少2个测试期WR > 阈值
  
单币有效 = 可能是噪音（BTC2022年特殊行情）
跨币有效 = 真正的市场规律
```
